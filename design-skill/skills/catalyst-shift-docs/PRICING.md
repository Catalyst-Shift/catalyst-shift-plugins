# Pricing in a document

This file covers only how a price appears in a document. How we price, what the offers are and what attaches to an engagement are strategy: they live in the current canon in `Catalyst-Shift/catalyst-brain` `strategy/` (see **Read canon first** in `SKILL.md`), not here.

## The rule

**Every price in a document comes from the teammate**, for this client and this scope. Not from canon, not from an older doc, not from memory, and never estimated.

- **No public price.** Never print a price list, a band, a range, a rate card, hours, or a day rate as the value — in any document, including for an assessment.
- A proposal or SOW states the **one price scoped for this client**. That is not a price list.
- If the teammate hasn't given you a price, leave the placeholder (`{{ENGAGEMENT_PRICE}}`, `{{CARE_MONTHLY}}`, `{{ASSESSMENT_PRICE}}`) in place and say so in your hand-back.

## How to write it

- **Use the number the teammate gives you**, and say in the doc that it is the fixed price for this scope.
- **Recurring lines** (the templates carry a care-contract monthly) appear only as the teammate states them. If canon and the teammate's scope don't include a recurring line, remove it from the template.
- **Crediting:** say an assessment is credited against later work only if the teammate tells you so. Otherwise don't mention crediting.
- **Partner or program terms** (discounts, rebates) appear only when the teammate says the deal runs through that partner and gives you the terms.
- **The guarantee** is defined deliverables and measured outcomes in writing, agreed before a dollar changes hands. Never "keep working at no cost."
- **Deck pricing slide:** show only the price scoped for this client. If the deck goes to an audience with no scoped price, delete the slide.

## A prior doc with old prices

If a teammate pastes a prior doc that prints a price list, a tier table, a band or a fixed public price, don't carry those numbers forward. Ask the teammate for the price for this client and flag what you removed.
