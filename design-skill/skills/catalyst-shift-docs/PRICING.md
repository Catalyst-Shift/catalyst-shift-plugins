# Pricing reference

Three published implementation tiers plus the platform retainer. Bake these in as defaults; teammates can override per-deal.

## Tier 01 — Diagnostic

- **Fee:** $12,000
- **Duration:** 30 days
- **What it is:** A scoped assessment of the current growth + revenue ops setup. Output is a written diagnostic, a 90-day plan, and a recommendation on whether to engage further.
- **When to use:** New prospect, unclear scope, high-stakes engagement, or the founder wants a low-risk way to evaluate working with us.
- **Outcome guaranteed in writing:** A diagnostic document and 90-day plan delivered by day 30.

## Tier 02 — Foundation

- **Fee:** $35,000
- **Duration:** 60 days
- **What it is:** Install the core growth infrastructure — lead-gen system (Kevin) + sales close system (Lucas). Done by day 60, handed off to the founder's team.
- **When to use:** Default engagement. Founder is ready to install, has internal capacity to operate it post-handoff, doesn't need ongoing optimization.
- **Outcome guaranteed in writing:** Lead-gen system + sales close system installed and operational by day 60. Specific metric targets defined in the SOW.

## Tier 03 — Operating Layer

- **Fee:** $45,000+ (scopes up based on complexity)
- **Duration:** 90 days
- **What it is:** Foundation tier + Catalyst OS. The proprietary **operating layer** that runs the growth + revenue functions whether the founder is paying attention or not. Includes integration with their stack (CRM, marketing tools, comms).
- **When to use:** Founder wants the system to keep running without their attention. Higher complexity stacks. GovCon / cybersecurity / industrial verticals where ops layer matters most.
- **Outcome guaranteed in writing:** Foundation deliverables + Catalyst OS installed and operating by day 90.

## Platform retainer

- **Fee:** $3,000–$8,000 / month (sliding by stack complexity and engagement scope)
- **What it is:** Ongoing optimization on Catalyst OS. Continuous tuning, new playbook deployment, integration maintenance, monthly review.
- **When it kicks in:** Default continuation after Tier 02 or Tier 03. **Most engagements continue** here.
- **Note:** Zero active retainer clients today. Do not fabricate adoption numbers.

## How to write pricing in a doc

- **Always state the fee in numbers.** "Investment: $35,000" beats "Investment: discussed during scoping."
- **Always state the duration.** "60 days" not "a few months."
- **Always state the guarantee.** Use the phrase "in writing" — every engagement has measurable outcomes defined before start, miss them, we keep working at no cost.
- **Frame the retainer as the default continuation.** Use "Most engagements continue" wording.
- If the teammate gives you a custom fee, use it. Note in the doc it's a custom scope and explain why (single line is enough).
